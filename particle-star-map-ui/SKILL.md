# 粒子星图关系网络 UI

将任意关系网络做成可展示、可操作、可复用的星图，而不是把普通流程图简单换成圆形。适用于产品关系、知识网络、系统依赖、组织关联等需要粒子星图背景的界面迁移。

## 何时使用

- 用户明确要求“星图、粒子、星星、关系网络、StyleKit particle”视觉或交互。
- 需要把既有关系图迁移到粒子星图，同时保留现有 API、权限和数据模型。
- 需要先做独立原型，再接入生产页面并验证交互性能。

不要把它用于普通后台表格、组织树或不需要粒子/星图体验的通用图表。

## 工作流

1. 先写视觉契约：深色近黑背景、低密度粒子/点阵、圆形节点、节点下方标签、直线关系、选中节点核心与双层光环。确认是否保留浅色主题和切换入口。
2. 用脱敏的代表性数据做独立原型，先验证节点比例、标签、点击、拖拽和缩放，再迁移到现有页面；不要为视觉改造重写后端。
3. 将数据语义与渲染分离：保留既有对象类型、关系方向、权限过滤和 API；以独立 particle 组件/主题接入，避免影响原有图引擎主题。
4. 生产接入后先做构建和浏览器验证，再部署。部署必须有备份、暂存目录、静态资源校验、服务器配置校验和可回滚版本。

## 页面组成与视觉系统

- 页面外壳、图谱画布和详情/状态层分开定义：外壳负责标题、返回路径、主题切换和搜索；画布负责粒子、节点和连线；状态层负责图例、操作提示、加载/空数据/错误反馈。
- 将背景色、渐变、粒子密度、节点颜色、描边、光环、阴影、文字层级、间距、圆角和动效时长做成设计令牌，禁止把关键比例散落在多个组件的魔法数字中。
- 图例必须与对象类型颜色一致；工具栏和提示层不能遮挡节点或吞掉画布指针事件。长标题、长标签和窄屏时要有截断、换行或安全边距规则。
- 明确组件边界：星图渲染器、节点、边、粒子层、缩放/重置控制、图例、详情抽屉（如有）、加载骨架和错误提示可以独立测试和替换。
- 响应式策略优先保证可读性和可操作性：小视口降低粒子数量、缩短标签、扩大点击热区，但保持节点/光环的相对比例；不以挤压或隐藏关键关系来“适配”。

## 不可破坏的渲染约定

- 布局是确定性的固定星座：同一数据和视口得到稳定位置，不使用持续运行的力导向或每帧重排。
- 进入某个焦点节点的视图时，以该节点为中心；按业务定义的“直接归属/依赖/连接”关系确定锚点，找不到时回退到最接近的父节点，再回退到当前/首个节点。
- 节点按对象类型和内部 ID 稳定排序；用最小间距松弛、环形/螺旋分布或打包算法消除重叠，保留轻微确定性扰动。不要把所有节点堆在一条直线上。
- 参考比例可配置：未选核心半径约 15、节点环约 32；选中核心约 30、内光环约 58、外光环约 80；标签放在节点下方（约 `y + 56`，选中约 `y + 94`），不要把长文本塞进圆心。
- 关系线保持直线，节点可以散落在不同高度；线条用低透明度细线，选中节点可提升关联线亮度，但不隐藏其他节点。

## 交互约定

- 单击节点才激活当前星：核心放大、显示双光环和标签；其他节点保持可见且等比例缩小/降亮，不做“只剩邻居”的隐藏。
- 悬停只做轻微描边/光晕提示；不要因为悬停改变布局。画布空白处可清除选择（若产品需要）。
- 支持画布拖拽和平滑滚轮缩放，限制缩放范围；拖拽速度应有明确倍数且不产生漂移。支持 Enter/Space 键激活有焦点的节点。
- 标签优先展示可读名称，必要时脱敏账号、联系方式或其他敏感标识；选中状态、焦点状态和减少动效模式都要有可辨识反馈。

## 数据、安全与性能

- 任何原型/截图/日志均使用脱敏数据，不把真实密钥、手机号、生产地址或凭据写入技能、源码示例或提交记录。
- 粒子数量设上限（原型约 70–80 个），动画使用适度 CSS/Canvas，遵守 `prefers-reduced-motion`。避免昂贵的每帧物理计算。
- 重型图引擎只在其他主题需要时加载；particle 主题应可在 API 慢或未登录时先渲染壳层，再展示加载、超时和错误状态，禁止整页白屏。
- 选择和布局状态应与数据刷新解耦；刷新不应把用户正在看的中心节点悄悄改掉，除非节点已不存在。

## 验证与交付

- 本地至少执行类型检查和生产构建；浏览器检查首屏、节点点击/取消、拖拽、滚轮缩放、键盘操作和窗口尺寸变化。
- 检查浏览器 console 无新增错误；验证静态 index、哈希 JS/CSS 返回 200，健康检查返回 200；受保护接口未登录返回 401 属于预期。
- 对真实登录/认证路径在目标环境中验证 API 联动；无法模拟时明确记录为待现场验证，而不是宣称已通过。
- 部署前保留旧版本和数据库备份，执行服务/代理配置校验，部署后做一次回归并提供回滚路径。
